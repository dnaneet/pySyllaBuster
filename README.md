# pySyllaBuster 🧠📚

**pySyllaBuster** is a Python-based tool designed to help students and educators analyze syllabi and extract key information for academic planning. It leverages natural language processing to identify topics, deadlines, and structure from syllabus documents.

## Features
- 📄 Parses syllabus text files for structured insights
- 🗓️ Extracts dates, topics, and assignments
- 🧠 Uses NLP techniques for semantic understanding
